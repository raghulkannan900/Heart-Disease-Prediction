# Heart Disease Prediction System

## About the Project
A web-based Heart Disease Prediction System built using Python, Django, and Machine Learning.

## Features
- User Registration
- User Login
- User Dashboard
- Heart Disease Prediction
- Machine Learning Model Integration

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- Pandas
- Scikit-learn

## Dataset
Heart disease dataset sourced from:
https://github.com/mrdbourke/zero-to-mastery-ml

## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Set the DJANGO_SECRET_KEY environment variable.
5. Run database migrations:

   python manage.py migrate

6. Start the server:

   python manage.py runserver
